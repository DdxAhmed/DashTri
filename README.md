# DashTri (TriModalDash)

A high-performance, real-time Tri-Modal Industrial Telemetry & Diagnostic Dashboard built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Tri-Modal Telemetry & Diagnostic Suite**:
  - **Vibration Analysis Widget**: Spectral FFT, peak velocity, acceleration metrics, and anomaly detection.
  - **Acoustic Monitoring Widget**: Decibel levels, frequency bands, ultrasonic anomaly indicators.
  - **Kinematics Widget**: Angular velocity, displacement tracking, mechanical shock detection.
  - **Thermal & Current Widget**: Power consumption, phase current monitoring, thermal runaway guardrails.
  - **AI Health Matrix Widget**: Machine learning health scoring, predictive time-to-failure (TTF), degradation curves.
- **Interactive Fault Injection Bench**: Test edge cases and trigger synthetic mechanical, thermal, and sensor anomalies.
- **Trip Hazard Banner & Real-time Alerts**: Instant warning overlays for out-of-spec telemetry thresholds.
- **Live Event Stream & Log Recorder**: Searchable, timestamped audit log of diagnostic anomalies and system events.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/DdxAhmed/DashTri.git

# Navigate into the project directory
cd DashTri

# Install dependencies
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized production bundle:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
